ID: app-uniform-corner-radius
DOMAIN: app
NAME: One large corner radius on every surface
SEVERITY: 3
SIGNATURE: app|surfaces|single-corner-radius-value+applied-to-all-controls
SIGNALS:
  - Four or more radius declarations in one view file, all with the same value
  - The shared value is 8 or more points: CornerRadius="16", .cornerRadius(16), 16.dp
  - Buttons, text fields, cards, sheets and images all use that one radius
  - ImGui styles set WindowRounding, FrameRounding, ChildRounding and GrabRounding equal
STATIC_RULES: app.uniform-radius
WHY:
  A single radius pasted on every element erases the difference between a control, a
  container and a sheet. Generated app UIs reach for 12 or 16 everywhere because it looks
  soft in a screenshot.

FIX:
